六、自动续期工作原理

Certbot 的自动续期机制具有以下特点：

  1. 检查频率：系统每天随机时间运行两次证书检查
  2. 续期条件：仅当证书剩余有效期少于 30 天时才执行续期
  3. DNS 验证：使用配置好的阿里云 API 自动完成验证，无需人工操作
  4. 续期后操作：成功续期后自动执行我们配置的 Nginx 重载脚本
